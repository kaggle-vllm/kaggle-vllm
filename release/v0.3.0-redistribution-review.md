# v0.3.0 runtime redistribution review — open

**Publication blocker:** the 6.6 GB runtime-v3 archive and any repackaged wheelhouse must not be uploaded publicly to Hugging Face until a human reviews every third-party wheel's license, notices, and binary redistribution terms. The [machine inventory](v0.3.0-license-inventory.json) lists 196 wheels. It found five with no declared license in wheel METADATA; all 196 retain `MANUAL_REVIEW` status. This document does not approve redistribution.

Using the already-uploaded corrected private Kaggle Input Datasets for a fresh acceptance run is a separate act from creating a new **public** Hugging Face binary distribution. The acceptance runner copies pinned wheels only into `/kaggle/working` in that session and publishes nothing. The three-file native-wheel fallback Dataset must be reviewed for visibility and redistribution rights before creation; saved P31 Notebook Output reuse is preferred.
