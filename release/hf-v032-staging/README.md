# kaggle-vllm binary release namespaces

Historical root paths and pinned commits remain valid. v0.2.0 is T4x2/cu128; v0.3.2/l4x4 is the proposed cu129 native wheel and metadata namespace. Its 168 locked dependencies are fetched from the original PyPI, PyTorch and FlashInfer publishers using exact checksums; dependency wheels are not mirrored here. The v0.3.2 namespace is not public or accepted until all sources, notices, immutable revision and manual Kaggle evidence are verified.
