# kaggle-vllm binary release namespaces

Historical root paths and pinned commits remain valid. v0.2.0 is T4x2/cu128; v0.3.2/l4x4 is the proposed cu129 metadata namespace; its exact native wheel is already hosted at v0.3.0/l4x4/native/vllm-0.30.0-cp312-cp312-linux_x86_64.whl. Its 168 locked dependencies are fetched from the original PyPI, PyTorch and FlashInfer publishers using exact checksums; dependency wheels are not mirrored here. The v0.3.2 metadata namespace is not public until its sources, notices and immutable revision are verified. Manual Kaggle GPU acceptance remains pending.
