# Public installation
The documented `python -m pip install "kaggle-vllm==0.3.2"` cannot yet succeed from public PyPI because 0.3.2 is absent. The SDK parser supports `kaggle-vllm bootstrap --profile kaggle-l4x4-cu129 --strict`, but public runtime bootstrap is intentionally blocked by the null immutable revision and missing Hub namespace. No public installation or Kaggle GPU acceptance was claimed.
