# Code of conduct

Project participation must remain respectful, technically honest and focused
on improving the work. Harassment, discrimination, threats, doxxing and
deliberate misrepresentation of evidence are not acceptable.

Maintainers may edit or remove abusive content and restrict participation when
necessary. Report conduct concerns privately through the maintainer contact or
GitHub moderation/reporting tools; do not disclose sensitive personal details
in a public issue.

Technical disagreement is welcome. Critique claims with reproducible evidence,
state uncertainty clearly and distinguish upstream behavior from this SDK's
behavior.
