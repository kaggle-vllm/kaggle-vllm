# Generated tables

Generated CSV and paper-table outputs belong here. Do not transcribe benchmark
values manually.

Current generated tables cover the canonical hardware/runtime, candidate model
matrix, exact workload matrix, five-model M4 compatibility gate, M1/M2 results,
M3 statistical summary and fit, M1–M3 evidence linkage, and paper claim
boundaries. M4 principal crossover and external
validation tables are intentionally absent until accepted principal and
independent-validation evidence exists.
