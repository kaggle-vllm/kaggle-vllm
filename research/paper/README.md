# Paper package

`outline.md` is the claim-disciplined manuscript skeleton. Numerical results
must be inserted only from `research/tables/` and figures from
`research/figures/`; both are generated from machine-readable evidence by
`research/analysis/generate_figures.py`.

The current package supports M1–M3 sections. M4 and independent-validation
result prose remains intentionally blocked until repeated Kaggle shards are
accepted and assembled. `research/PUBLICATION_READINESS.md` is the release gate,
and `research/claim_boundaries.json` is the machine-readable claim policy.
