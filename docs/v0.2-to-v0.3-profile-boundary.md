# Preserved T4 and new L4 profiles

| SDK generation | Profile | Kaggle GPU | SM | TP | Upstream vLLM |
| --- | --- | --- | ---: | ---: | --- |
| 0.2.x | `kaggle-t4x2-cu128` | 2 × Tesla T4 | 75 | 2 | 0.18.1 |
| 0.3.0 | `kaggle-l4x4-cu129` | exactly 4 × NVIDIA L4 | 89 | 4 | 0.30.0 |

The historical T4 profile, overlay lock, SHA pin, Hugging Face revision, branches, tags, assets, model repository and documentation remain intact. v0.3 packages both profile data sets. CLI bootstrap, environment, and doctor require `--profile`; the T4 path delegates to the existing v0.2 implementation. `KaggleLLM` detects an exact T4×2 or L4×4 Kaggle topology conservatively when no profile is passed, and raises on ambiguity. Passing `profile=` is preferred in reproducible notebooks.

The L4 binary repository namespace is proposed as `v0.3.0/l4x4/` in `waqasm86/kaggle-vllm-binaries`. Its immutable commit field remains unset until upload; online bootstrap refuses mutable `main`. The historical `waqasm86/kaggle-vllm-models` Qwen TP=2 files are unrelated to this native runtime.
