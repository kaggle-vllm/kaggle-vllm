# Security policy

This project is an alpha compatibility and runtime-delivery toolkit. Only the
latest released SDK and current development branch receive security fixes.

Please report vulnerabilities privately through the GitHub repository's
Security Advisories feature. Include affected version/commit, impact, minimal
reproduction and whether the issue requires an untrusted artifact, local
filesystem access or network exposure. Do not include live tokens, credentials
or private model data.

Public issues are appropriate for ordinary bugs without security impact. See
[security and supply chain](docs/security.md) for the trust boundary and safe
operation model.
